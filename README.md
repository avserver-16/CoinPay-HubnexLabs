# CoinPay – UI/UX User Flow Prototype

**CoinPay** is a **UI/UX-based user flow prototype** designed and developed within **24 hours** as part of a task to showcase rapid prototyping and design implementation skills.

##  Overview

This project focuses on creating a **smooth, intuitive user experience** for a payment application. The prototype demonstrates core user flows such as onboarding, wallet overview, and transaction navigation.

* Built entirely as a **frontend UI/UX prototype** (no backend integration).
* Emphasis on **clean design**, **responsive layouts**, and **interactive navigation**.
* Developed within a **tight 24-hour timeframe** to simulate real-world rapid prototyping.

##  How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/avserver-16/CoinPay.git
   ```
2. Navigate to the project folder:

   ```bash
   cd CoinPay-HubnexLabs
   ```
3. Install dependencies:

   ```bash
   npm install
   ```
4. Run the app (Expo):

   ```bash
   npx expo start
   ```
